# Alex R45 — 儿童凭据撤销后的实时语音与对话隔离

## 根因与改动

此前 `POST /api/learners/revoke` 只撤销儿童登录凭据和会话，`POST /api/learners/set-pin` 在重置 PIN 后也仅撤销登录会话。**进行中的模型生成、录音缓冲、实时转录、云端 TTS 和 Voice Turn 仍可能持有旧的 principal 并继续执行。**

R45 统一接入 `revokeLearnerRuntime`，在这两个家长操作成功保存凭据后：

1. 撤销指定学习者当前所有浏览器会话。
2. 向其正在进行的 Companion 流式文本请求发送中断信号。
3. 停止短音频入口和录音分片缓存。
4. 结束该学习者的实时转录会话。
5. 停止该学习者的 TTS 播放会话与 Voice Turn。

所有清理以 `learner:<profileId>` 限定作用域，不影响家长、共享儿童或其他独立学习者。若某个取消器失败，仍继续尝试其他取消器，最终抛出 `AggregateError`，**不得将局部失败伪报为全部成功**。

## 验证覆盖

- 单元测试：合法作用域、无可选供应商、跨孩子隔离、非法 profile 参数、取消器失败后的聚合错误。
- Voice Turn 受控异步测试：模型服务忽略 AbortSignal 的迟到回复不会发起 TTS；迟到 TTS 会话创建会被撤销；取消孩子 A 不影响孩子 B 的活动会话。
- 真实 Node HTTP 集成：家长撤销学习者凭据后，旧会话无法访问语音能力接口，旧凭据无法重新登录；重置 PIN 同样使旧会话失效，新 PIN 可登录，家长自己的会话保持有效。
- 家长控制台提示 PIN 重置或撤销会中断进行中的语音和文字会话。

## 仍未验证 / 不可越界声称

此轮测试包含模拟的延迟模型和 TTS 供应商，用于验证并发取消与状态所有权，**不是**真实云端 ASR、LLM 或 TTS 成功率验证。浏览器麦克风权限、音频播放质量、网络断开和设备上的真实声学环境仍需人工及独立端到端验收。现有 `R42` 发布门槛仍应将真实语音 E2E 标记为 `manual-required`。

下一阶段优先真实可观测语音验收证据、取消后媒体资源回收、异常超时与儿童连续会话实测；不能仅以自动化模拟测试数量替代实际使用体验。
