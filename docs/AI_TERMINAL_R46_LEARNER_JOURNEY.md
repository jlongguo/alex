# Alex R46 — 独立儿童学习旅程与恢复入口

## 目标

复用现有 `CompanionConversations` 的会话及文本练习证据、`LearningPlans` 的家长作业计划，不建立重复的儿童档案、聊天副本或第二个进度数据库。

`GET /api/learning/journey` 仅在 `AUTH_MODE=local` 下可用：

- 独立学习者登录：仅获得自己的最近会话 ID、模式、更新时间、回合数以及自己课程计划的完成数；带 `profileId` 参数的请求被拒绝。
- 家长登录：必须明确提交已存在的 `profileId`，才能查看对应学习者的元数据。
- 共享旧儿童账户：拒绝访问独立学习者旅程，防止混淆多个儿童。
- 未登录：拒绝访问。
- 响应不含对话原文、昵称、PIN、登录代码、音频数据及云端模型密钥。

前端在现有 Alex 互动终端下提供“我的学习旅程”。显示下一门待完成课程、任务完成情况及最近会话是否可继续；实际继续聊天仍复用原有「我的历史会话」入口和服务端所有权验证。

## 验证

- 无记录、暂停计划、完成计划、跨孩子计划和异常进度的单元测试。
- 真实 Node HTTP 测试：家长创建档案、设置独立凭据、孩子开启英语会话、家长分配课程、孩子查看自己的进度、家长选择档案查看、第二孩子隔离、儿童不能派发虚拟设备动作。
- 静态前端/接口验证：无设备控制按钮、所有动态课程名称经转义、服务端禁止共享儿童绕过独立身份。

## 上线边界

本轮的 `completedTextExercises` 与课程完成情况是**文字证据**，不能被解读为语言水平、发音质量、真实语音交互或机器人实际移动达标。REST 会话历史恢复已存在，本轮提供其便捷入口和统一状态投影；真实浏览器刷新后交互体验尚需单独手动验收。

后续 R47 优先发布安装、数据目录迁移、升级回滚、部署前检查。真实音频服务 E2E 和 ROS2/Nav2 运行验收仍是独立上线阻断项。
