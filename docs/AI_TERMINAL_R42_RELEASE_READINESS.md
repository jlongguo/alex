# Alex R42：软件内测上线门槛（只读）

## 产品目标

本轮不继续拓展 Skill 元数据生命周期，而是让家长和开发者清楚知道 **为什么 Alex 现在还不能发布为儿童软件内测版**。

家长登录后，在“家庭档案与记忆”中的“软件内测上线检查”点击“核对发布阻断项”。服务端读取当前真实状态，不修改任何 Skill、WAL、家长设置、学习档案或机器人设备。

## 报告范围

`GET /api/release/readiness`：仅 `AUTH_MODE=local` 并且使用家长会话可以访问。儿童会话返回 403，未登录返回 401。响应只提供检查 ID、类别、状态、简短说明，不输出任何用户密码、儿童档案细节、语音原文、签名或发布者私钥。

- **blocked**：本地身份认证不足、没有儿童登录设置、缺少学习档案、缺少录音输入供应商配置、持久化写入权不存在、Skill 跨存储不一致、单包或多包 WAL 尚待恢复、事务日志空间耗尽。
- **manual-required**：真实语音完整链路、儿童登录与学习旅程、备份/恢复演练还没有外部验收证据；这些检查不会因为配置存在或单元测试通过而自动置绿。
- **checks-complete**：仅表示该模型检查项已完整，并不授予上线许可。返回字段 `releaseApproved` **恒为 false**。
- **robotCandidate**：独立显示 Gazebo/Nav2 真实运行与物理安全仍未经证明，不会用 `sim:check` 或 `sim:preflight` 冒充运行时验收。

目前 HTTP 路由不接受客户端上传的“验收已通过”标志；真实验收结论尚未建设独立的证据入库和审批工作流。

## 如何本地核对

启动必须先配置本地家长身份与儿童凭据，并保留状态文件独占租约。打开家长区域中的检查面板，查看具体阻断项。修复配置后可以手动重新读取报告；不需要重建 Skill 或清空 WAL。

报告 **不是**健康检查的替代：`GET /api/health` 仅能说明服务进程可访问。真正上线必须分别验证语音、儿童权限、状态恢复和用户完整流程。

R45：真实语音 E2E 测试和取消/权限撤销
R46：核心用户旅程、异常断网与状态一致性
R47：发布打包、升级与回滚和安装检查
R48+：实测缺陷收敛和候选软件内测发布验收

版本轮次是计划，不是交付承诺；实际取决于运行环境证据与外部服务测试结果。
