# Alex R44 — 家庭首次使用引导

本轮从已有的真实业务接口组成面向家长的初始化流程，不创建另一份儿童身份或隐私数据副本。

## 流程

1. 家长通过本地认证登录。Demo 模式只供演示，不能进行真实家庭初始化。
2. 在“家庭档案与记忆 → 家庭首次使用引导”填写孩子昵称、年龄段和独立 PIN（6–12 位数字）。
3. 浏览器按顺序调用 `POST /api/profiles`、`POST /api/learners/set-pin` 和 `POST /api/learner/privacy`，偏好保存在现有各自的状态存储中。
4. 云端文字、云端录音识别、云端语音合成、浏览器语音识别与朗读权限**全部默认关闭**。需要云端功能时，必须在已有“学习者专属 AI 与语音隐私”表单中由家长单独授权。
5. 初始化完成后，家长私下保存孩子的登录代码。PIN 不回显；孩子通过独立代码和 PIN 登录。
6. `GET /api/family/onboarding` 是只读、家长专属状态接口，只输出步骤完成状态和档案 ID，不返回昵称、PIN、登录代码、密钥或孩子的对话。

## 故障和边界

- 三个状态文件分别持久化，**不是跨文件原子事务**。如果第二或第三步失败，已经创建的档案不会自动删除；界面明确指出失败阶段，引导家长在已有 PIN / 隐私表单继续补齐。
- 状态投影基于已经落盘的配置，并不代表语音服务、学习质量、孩子实际体验或设备导航通过验收。
- 只允许家长读取初始化概况。共享儿童与独立学习者会话均不能修改隐私授权。
- 不会从孩子的昵称推断实名、生日或其他不必要的个人信息。
- 按年龄段、登录凭据、隐私独立授权的真实路径完成后，R42 发布检查仍会将真实语音 E2E、儿童使用旅程和完整恢复演练保持待验收。

## 验证

R44 单元测试覆盖创建顺序、同一学习者隐私核对、Demo 拒绝和 PII 不回显。HTTP 测试启动真实 Node 服务，验证家长创建、独立学习者登录、儿童拒绝越权、云端默认关闭以及重启后的状态恢复。前端静态测试核对授权入口、PIN 输入与默认拒绝字段。

下一轮 R45 聚焦真实录音→识别→AI 回复→播放的语音用户旅程、取消及隐私权限撤销，不用 mock 测试冒充云端提供商验收。
