# 家长登录与本地授权入口

Alex 的 `AUTH_MODE` 默认是 `demo`。**演示角色切换不是已认证的家长会话**：演示模式不能配对虚拟设备、授予设备能力、审批计划，也不能修改家庭私有数据。

## 本地家长模式（Mac/Linux）

安装依赖后，从项目目录运行：

```bash
pnpm install --frozen-lockfile
bash scripts/start-local.sh
```

启动脚本会在终端无回显地询问家长密码（至少 12 个字符），并将 `AUTH_MODE=local` 及密码传入本次运行的 Node 服务，**不会写入文件或前端页面**。也可以自行在受信任的运行环境中设置 `ALEX_PARENT_PASSWORD` 后调用该脚本。默认只监听 `127.0.0.1`。

儿童登录是可选的：启动前设置 `ALEX_CHILD_PIN` 为 6–12 位数字。例如：

```bash
ALEX_CHILD_PIN=681274 bash scripts/start-local.sh
```

请替换示例 PIN；不要在公开服务器、截图或仓库中保存真实凭据。

1. 重新打开 `http://127.0.0.1:4317`，将自动出现「家庭中枢登录」。
2. 选择「家长」，输入终端中刚设置的密码。
3. 顶部显示「家长已验证」后，进入「设备与机器人」「Agent 与任务」「家庭与设置」。所有操作仍需后端权限校验。
4. 儿童登录时可点击顶部「切换为家长」，先退出儿童会话，再输入家长密码。没有儿童 PIN 时，不能使用儿童登录。
5. 点击「退出」将删除会话 cookie 并返回登录界面；重新启动服务会使内存中的旧会话失效。

## 演示模式

运行普通 `pnpm start` 时，如果未额外设置认证环境变量，顶部显示「演示模式 · 无家长授权」和「启用家长授权」。点击后显示**启动指南**，而不是伪造一个可授权的登录状态。必须在服务器端启用本地认证才能获得家长权限。

如果顶部入口缺失，检查页面是否使用最新源码并强制刷新（Ctrl/Cmd+Shift+R）。不要修改 `AUTH_MODE` 为 demo 来绕过登录。
